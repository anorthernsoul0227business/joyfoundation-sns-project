## 経緯

書影を索引化した際、表紙の惹句に以下が含まれていることが判明した。

| 書名 | 惹句（抜粋） |
|---|---|
| 屋久島 癒しの清流音CDブック | 「ガン専門病院・精神科・皮膚科…国内外の医師が治療に活用!」「うつ・不眠症が軽快」 |
| 屋久島の清流音 自律神経が整うCDブック | 「うつ イライラ 不眠 パニック障害 アレルギー 腰痛 ガン 美肌」 |
| 宮古島 癒しの波音CDブック | 「更年期障害が消えた」「脳性まひの後遺症が改善」「不眠・不安障害が治った」 |
| 音のシャワーで目がよくなるCDブック | 「有効率85%!」「視力0.3が0.9になった!」「老眼鏡が不要!」 |
| ハワイ 絶景の癒し音CDブック | 「30万人が効果を実感!」「うつ、不眠、アトピーが改善」 |

**「ガンが治ると書いてある」と伝えたところ、圭一郎さんは悪印象を示した。**
出版社側の売り文句であり、本人の見解ではない可能性が高い。

これは RULE-0001（効果の断言禁止）が圭一郎さん自身の指示（2026-03-11）から
出発していることと整合する。**過去の出版物の表現方針と、現在のSNS表現方針は明確に異なる。**

## 「帯を外す」では解決しない

11点のうち **8点がムック**（マキノ出版ムック／宝島社TJMOOK）。
ムックは雑誌形態のため、**惹句は表紙そのものに印刷されており外せない**。

帯を外して対応できるのは `IM-0035`（青春出版社『聴くだけで体が変わるサウンドヒーリング』）
1点のみ。Drive・ローカルを検索したが、帯なし版・別バージョンの書影は存在しなかった。

## 使ってよい表現

出版実績そのものは強い信頼シグナルであり、効果を語らずに書ける。

- 「宝島社、マキノ出版、青春出版社から刊行しています」
- 「東邦大学医学部教授の有田秀穂先生に監修いただきました」
- 監修者の顔ぶれは Evidence カードの著者と重なる
  （西條一止＝EV-0001/0003/0004 の著者、信田広晶＝EV-0005/0008 の著者）
  → 学会発表と出版物が同じ専門家に支えられている構造を示せる

## 書影の扱い

| 使い方 | 可否 |
|---|---|
| 文章で刊行実績に触れる | 可 |
| 書影をそのまま投稿画像にする | **不可**（惹句が読める） |
| 書影を並べて小さく見せる（文字が読めないサイズ） | 要検討。「量」の訴求はできる |
| タイトル部分のみトリミング | 要検討 |
