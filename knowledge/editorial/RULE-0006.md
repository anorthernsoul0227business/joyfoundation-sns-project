---
id: RULE-0006
category: S1
rule: 研究の限界は事実として書くが、独立した見出しを立てて強調しない
reason: |
  限界を1セクション割いて書くと、構造として「変化がなかったこと」が記事の主役になる。
  読者には「変化がないことがメリットなのか」と誤読され、信頼どころか
  「それって意味あるの」という印象を与える。事実として書くことと強調することは別。
alternatives:
  - 本文の流れの中に「〜という報告があります。ただし参加者は7名と少なく、〜については変化がありませんでした」と一文で織り込む
  - 限界に触れたあとは肯定的な内容に戻して締める（限界で終わらせない）
scope: 全媒体（特に note などの長文）
source: 康二郎さん 2026-07-29 ループ検証レビュー
status: active
---

## 補足

**やってはいけない構成の例**（2026-07-29 の生成物で実際に発生）:

```
## 同時に、変わらなかったものもあります
正直に書きます。
この研究では、心拍変動の指標に変化はありませんでした。…
参加者は男子学生7名。とても小さな研究です。
「効果が実証された」と書けるような話ではないのです。
```

見出し＋数段落を割いており、記事の中心が「効果がなかった」話になっている。

**望ましい形**: 数値を紹介した直後に一文で添える。

```
…という報告があります。ただし参加者は7名と小規模で、
自律神経のバランスを示す指標には変化がありませんでした。
それでも、寝る前の10分を水の音にあててみることは今夜からできます。
```

**限界を書かない、という意味ではない。** RULE-0001（効果の断言禁止）は引き続き有効。
書く位置と分量の問題である。
