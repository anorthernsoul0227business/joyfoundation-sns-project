note #1
北海道から届いた「音の癒し」実践レポート
エステ×サウンドヒーリングで見えてきた「思考が現実を創る」という真実

北海道でエステサロン「サロン・ド・ボーテ・エクラ」を営む新谷香代さん。サウンドヒーリング協会のセラピスト10期生として資格を取得後、エステの施術にサウンドヒーリングを取り入れ始めました。

新谷さんが実感した変化
「お客様の心身の変化を間近で見ているうちに、自分自身も変わっていきました。『思考・感情が現実を創る』という言葉を、身をもって体験したのです。」

エステで体を整え、サウンドヒーリングで心を整える。この組み合わせが、クライアントの自己変容を促すことを、新谷さんは日々の施術の中で確認しています。

サウンドヒーリングは、特別な場所でなくても実践できます。日本最北のサロンから届いたこのレポートは、「どこでも、誰でも、音の力を活用できる」という希望のメッセージでもあります。

続きは協会の研修会で学べます
出典: 2011年協会誌 P4-P5「セラピスト活動報告」
note #2
学習塾に「音の癒し」を導入してみた結果
子どもたちのストレスケアに、サウンドヒーリングができること

学習塾「れもんの木」を運営する藤部久子さん（セラピスト11期生）は、子どもたちの学習環境にサウンドヒーリングを取り入れる試みを始めました。

受験勉強、習い事、友人関係...。現代の子どもたちは、大人が想像する以上のストレスを抱えています。藤部さんは、そんな子どもたちに「音による安らぎ」を提供したいと考えました。

教育現場での気づき
「勉強の前に数分間、自然音を聴くだけで、子どもたちの集中力が変わりました。音は、学びの土台となる『心の安定』を作るツールになり得るのです。」

学校でも塾でも、「成績」という結果が求められる場所。でも本当に大切なのは、子どもたちが安心して学べる環境ではないでしょうか。

サウンドヒーリングは、教育現場に新しい可能性を開きます。「学ぶ」と「癒される」が共存する空間づくり。それは、これからの教育に必要な視点かもしれません。

教育関係者向けワークショップも開催中
出典: 2011年協会誌 P6-P7「私の活動・ストレスケア in 学習塾」
note #3
「体感音響」の効果を学会で発表しました
第76回日本温泉気候物理医学会での研究報告

「サウンドヒーリングって、本当に効果があるの？」

この疑問に科学的に答えるため、サウンドヒーリング協会では継続的な効果測定を行っています。2012年、その成果を日本温泉気候物理医学会で発表しました。

体感音響セッション前後の変化
顔面水分量 32.7% → 40.4%
手掌温度 29.67℃ → 31.42℃
足部温度 21.8℃ → 24.3℃
状態不安指数 39.52 → 28.28

肌の水分量が上がり、末端の冷えが改善され、不安感が軽減される。これらの変化は、体感音響が自律神経のバランスを整え、リラックス状態を促進していることを示唆しています。

研究の意義
「なんとなく気持ちいい」という感覚を、客観的なデータで裏付けること。それが、サウンドヒーリングをより多くの人に届けるための第一歩だと考えています。

私たちは、「感覚」と「科学」の両方を大切にしながら、音の可能性を探求し続けます。
