- 大目標: **「健康になるトラック」＝乗れば乗るだけ健康になる**

## 5. サウンドヒーリング側の説明（圭一郎さんの見解）

### 健康の定義と機序
- 健康＝**心が穏やか＝心拍が安定＝自律神経のバランスが取れている**状態
- 安心感＝扁桃体の警戒スイッチを解くこと。人混みでは常に警戒モードになっている
- 聴覚は「聞いていなくても聞いている」。**正面より後方の音がよく聞こえる**（背後警戒のセンサーが常時働いている）→ 騒音は無自覚に疲労させる
- 飛行機・船の騒音（500〜1000Hz以下の低音）は見過ごされている環境問題。機内騒音は車内より大きく、疲労の原因になる

### 過去の実験知見
- 自然音を聞かせた作業実験（50分×1回）: 作業効率に科学的有意差はなかったが、**ミスは自然音の方が少なく、自然音は集中力を邪魔しない**ことが分かった → 運転への応用可能
- **西条先生（※表記要確認）との実験: 自然音を10分聞くだけで自律神経に変化** → **最低10分で効果が期待できる**
- マイクロレスト（細かな休息）の概念（ハーバードの研究に言及 ※要確認）
- ビクトリーポーズを1日1回行うだけでポジティブなホルモンが出る（イギリスの研究に言及）
- アロマ（香り）は嗅覚順応で直後に感じなくなる＋消耗品でコスト大 → **音が最もコストパフォーマンスが良い**
- 視覚要素は「壁を緑にする」のではなく、小さな植物をテーブルに置く程度が良い

### 運用方法の推奨
- **運転席に座ってエンジンをかけたら自然音がずっと流れ、一定音量で聞き続ける**（運転中は常時再生）
- 朝と夜で体内コンディション（自律神経）が違うことを理解した上で音を使い分けることが重要
- 運転前の生活習慣提案も可能（出社時の音、過ごし方の提案）→ クライアント側も「それは大丈夫（提案可）」と了承
- **まず波動研究所のオフィス内で自然音を流すことからスタートすることを推奨**（事務作業中でも効果あり）
- 事例: 無農薬野菜を40年扱う会社（横浜・都内3店舗）では全店舗で自然音を流している
- 「涼しく感じる」効果から熱中症予防への展開も可能（自律神経バランスによる）

## 6. 効果測定の方法（実証実験の設計材料）

| 方法 | 内容・留意点 |
|---|---|
| **POMS（心理テスト）** | 35項目のアンケート。**最も簡便で会議的にやりやすい**。出発前・（運転直後）・帰着後の3回実施して変動を見る |
| 心拍数・血圧 | 日常の心拍数、上下の血圧の変化を見る。ただし直前の心理的要因（喧嘩等）で乱れるため、**測定前に5〜10分の安静が必要** |
| 唾液検査 | オキシトシン・セロトニン・コルチゾール等のホルモン測定が可能。**採取後すぐ冷凍が必要**（冷凍ポットがあれば運転直後の採取可）。費用は高め |
| 波動測定装置 | クライアント側が保有。**先方は波動測定をぜひ実施したい意向**。他データとの整合性・連動性を確認しながら、多くの人に理解される形を目指す（社会的評価は未知数なため表に出すかは別途判断） |

- 実験設計の方針: 何人かをピックアップし、年代別・条件を揃えて実施。**1回で完結させず、やり方を修正しながら複数回**行う
- 運転コース（都心型/郊外型）によってドライバーが受ける影響が異なる点も検証対象として面白い、という認識で一致

## 7. クライアント側からの質問と回答

1. **自然音は最低どのくらい聞けばよいか** → 運転中は常時再生が基本。実験知見では最低10分で変化が出る
2. **若い人と年配で効果の差はあるか** → 一概に言えない。自然が好きか等の嗜好による。ロック好きな人は最初「ぬるい」と感じることもあるが、継続すると（自然音は聞き流せるため）馴染む
3. **事務員のPC作業中でも効果はあるか** → 「絶対いいと思う」。まず研究所内で流すことを推奨
