## 1. 提案の骨子（3段構え）

**クライアントの理念「まず自社の社員を健康にする」に沿って、①研究所オフィスへの音導入 → ②トラック実証実験 → ③量産・車両組込み の3段階で進める。**

| フェーズ | 内容 | 時期の目安 |
|---|---|---|
| **第0段階: オフィス導入** | 波動研究所のオフィス内で自然音を流すことからスタート | **8/21訪問時に音源持参・即開始可能** |
| **第1段階: トラック実証** | スマホ＋車載Bluetoothスピーカーの最小構成で実証実験 | 音源・方式の検証後 |
| **第2段階: 量産・組込み** | 専用機器化 → トヨタ・いすゞへの設置位置指定 → 車両標準搭載 | 実証データ取得後 |

理由:
- 「まず社員から」はクライアントの企業理念そのもの。オフィス導入は理念に合致し、投資ゼロに近い形で今すぐ始められる
- 事務スタッフからも「PC作業中の自然音は効果があるか」という質問が出ており、社内の関心は既にある
- トラック実証は初期投資を抑えた最小構成で開始し、実証データを持って専用設計・メーカー連携に進む方が説得力がある

## 2. 第0段階: オフィス導入（8/21〜）

- 研究所オフィス内に自然音を流すコーナー／BGM環境を構築
- 必要機材: 据置スピーカー1〜2台のみ（数万円規模）。音源はジョイ側で選定して持参
- 「出社時に10分自然音を聞く」ルーティンの提案も可能（実験知見: **10分で自律神経に変化**）
- 参考事例: 無農薬野菜販売会社（横浜・都内3店舗）が全店舗で自然音を常時再生
- 効果の副次的な訴求: 「涼しく感じる」→ 熱中症予防（自律神経バランス）
- **狙い**: 社員自身が音の効果を体感 → トラック実証への社内理解・協力を得やすくする

## 4. 第1段階: トラック実証実験の推奨構成

### 4.1 再生デバイス: スマホ（会社支給を推奨）

- **専用アプリ**を限定配布（TestFlight / 限定APK / MDM配布）
  - 起動 → 大きな再生ボタン1つだけの画面（走行中操作なしをUIで担保）
  - **エンジン始動→再生開始したら運転中は常時再生**（7/31確定方針）。一定音量
  - 端末の時計で朝・昼・夜を判定し自動選曲。朝と夜で自律神経のコンディションが違う前提で音源を使い分け
  - **音源は端末内蔵（オフライン再生）**: 全国走行で通信不安定エリアがあるため。更新はWi-Fi時のみ
- **会社支給端末を推奨**: 音量・通知・他アプリの干渉を統制し実験条件を揃えるため（私物は条件が揃わない）
- 固定はカップホルダー型 or エアコン吹き出し口マウント

### 4.2 スピーカー: 車載Bluetoothスピーカー

- 車両による仕様バラつきを避けるため、実証では**後付けスピーカーで条件統一**
- 「音のシャワー」を満たす設置位置を実車で検証（サンバイザー裏／ヘッドレスト両脇／ダッシュボード上）
- 音量設計: 警音・緊急車両サイレンをマスキングしない上限を設定
- **体感音響の拡張**: Harmonic Massage を座席に組み合わせる拡張実験も提案可能
- エンジンON→Bluetooth自動再接続を事前検証

### 4.3 実証実験の測定設計（7/31協議を反映）

| 項目 | 設計案 |
|---|---|
| 規模 | 5〜10台・10〜20名。**都心型コース（納品時間長）と郊外型コース（運転時間長）の両方を含める**。年代別に条件を揃えてピックアップ |
| 期間 | 4〜8週間。前半は音なしのベースライン計測 → 音あり期間との**同一ドライバー内比較** |
| 主指標 | **POMS心理テスト（35項目）**: 出発前・運転直後・帰着後の3回で変動を測定（最も簡便・低コスト） |
| 副指標 | 心拍数・血圧: **測定前に5〜10分の安静**を確保する運用込みで設計（直前の心理要因の交絡を排除） |
| オプション | 唾液ホルモン（オキシトシン・セロトニン・コルチゾール）: **採取後すぐ冷凍**が必要 → 冷凍ポットを車両または営業所に配備できる場合のみ実施。費用高め |
| 併用 | **波動測定装置（クライアント保有）**: 先方の意向により実施。POMS等の他データとの整合性・連動性を確認する位置づけ（公表するかは別途判断） |
| 反復 | **1回で完結させず、やり方を修正しながら複数回実施**（7/31合意済みの方針） |

## 5. 第2段階: 量産・車両組込み

- 実証結果を基に専用再生機器（物理スイッチ＋内蔵ストレージ＋専用アンプ）を設計
- 実証で得た最適スピーカー位置を「指定位置」として**トヨタ・いすゞ**（現行使用メーカー）への要請に活用
- 将来の車両標準搭載時は機器仕様をメーカー側に提供する形へ移行
- 横展開: 夜間の睡眠環境／工場／運転前の生活習慣提案（クライアント了承済み）— 同じ音源資産＋据置スピーカーで展開

## 7. リスク・検討事項

1. **安全面・法令面**: 走行中に操作させないUI設計は必須。音量上限の設計（サイレンをマスキングしない）
2. **Bluetooth自動再接続の信頼性**: 機種依存が大きい。実証前に候補機器で検証
3. **夏場の車内高温**: スマホ・スピーカーの耐熱（特にダッシュボード上）
4. **ドライバー受容性**: ほぼ男性・平均40歳前後の現場。嗜好差あり（ロック好きは最初「ぬるい」と感じる例も）→ 継続聴取で馴染む知見を説明に織り込む。「監視されている」と感じさせない同意設計
5. **効果表現**: 断言は避け「〜が報告されています」トーンで（POMSデータが揃うまでは特に）
