資格認定研修会
ウエルビーイングクリエイター資格認定研修会のご案内
音により人を癒す新たな仕事、
ウエルビーイングクリエイターをめざす方へ
未来を予測しにくい今、何が起きても自分の心の力を使い、喜び多い未来を創造する力を養います。
この研修会は、サウンドヒーリングの理論と実技力を深め、自分の内面を磨き、Harmonic Revolutionを啓蒙し、自らの意図で幸せになる力を培う実践的なリーダー養成研修会です。
サウンドヒーリングの３つのメソッドを活かし、社会の中でリーダーとなりウエルビーイング・ライフの総合的アドバイザーを目指します。 自分を信じ、固定観念にとらわれない、新しい価値観で自分の人生を創造し、人々の健康と美と心豊かなライフスタイルに貢献する人を養成する研修を、１年間かけて実践的に行います。第３期では、オンラインも活用し、プラベートに対話する時間も設けます。どうぞお早目にお申し込み下さい。
※日程および、研修・訓練内容は昨今の状況や受講生の状況を見ながら変更する場合もあります。
学び
どんな条件下でも結果を出せるサウンドヒーリング実技力と言葉で分かりやすく説明する理論的知識、人格的魅力を身に付けます。
クライエントの体調と状態に合わせ、トリートメントの流れを自分で考え、組立てる実技法を学びます。
協会公式イベントHarmonic Day、1dayレッスンなど、簡単レッスン法（実技と理論）の教え方を学びます。
脊椎両側の深層背筋を緩めて、心とからだの緊張を同時に緩める実技法を学びます。
自分自身にトリートメントするセルフトリートメント法を学びます。
基礎的体のしくみと心拍数から見る自律神経の働き、音の影響をより詳しく学びます。
未病のしるしの見分け方を知り、実技に活かす方法を学びます。
室内環境を自然音で快適にする（サウンドスケープデザイン）の初歩を学びます。
個人事業主としての税金の事を学びます。
訓練
日常生活の中で自分を深める呼吸と声を訓練します。
身体を緩める　呼吸と自律運動法を訓練します。
各自テーマを決め、学会や講演会などで発表する練習をします。
推薦する書籍（４－５冊）を各自で熟読します。
地域のクリニックや企業を訪問し、サウンドヒーリングを実践的に啓蒙し広める訓練をします。
