| 背景 | 自然音の疲労軽減エビデンスをジョイファウンデーションが先方に提示 → 「まず実験したい」との反応を得て具体化 |
| ジョイファウンデーションの役割 | 自然音源の提供 ＋ 音響システムの構築提案（音源選定はジョイ側が担当） |
| 康二郎さんへの依頼内容 | **システム構成とハード面の提案**（最も簡単・フレキシブル・環境適応できる方式） |

## 2. 利用環境・ユーザー（7/31 初回打ち合わせで確定）

- 車両: **2トン車がほとんど**（配送用。営業バンもあるがメインはトラック）。将来的には**数百台規模**での導入
- 現行メーカー: **トヨタ・いすゞ**
- ドライバー: **20代〜60代・平均40歳前後（やや若め）。ほぼ男性**（女性は漸増中だがわずか）
- 稼働エリア: 北海道〜沖縄の全国。**市街地・交通量の多い場所が中心**
  - **都市部**（東京・大阪・名古屋等): 運転時間は短め、降車して納品する時間の方が長い人もいる
  - **郊外・地方**: 納品先が遠く運転時間が長い → 運転疲労が大きい ← **主なターゲット**
- 勤務パターン: **基本昼間のみ・夜間走行はほぼ無し**（昼間の高速道路走行は稀にあり）。出勤 → トラック乗務 → 夕方帰社 → 夜帰宅
- バス・長距離など業務外への展開は現時点で対象外

## 3. 目的

1. 長時間運転による**疲労の軽減**
2. 注意喚起による**安全運転の支援**（事故の少ない運転）
3. 夜間の**睡眠の質**が安全運転につながるため、将来的には生活環境全体への音の提案

## 4. 機能要件

| # | 要件 | 詳細 |
|---|---|---|
| F1 | ワンスイッチ再生 | エンジンをかけてスイッチを入れるだけで自然音が流れる。**走行中の操作は一切不要** |
| F2 | 時間帯別音源 | 朝・昼・夜で最適な音源を、ユーザーが考える工程なしに自動提案・再生（朝と夜で自律神経のコンディションが違うことを前提に使い分ける） |
| F3 | 音源 | 森・海・高原などの自然音（ジョイファウンデーション保有）。運転の邪魔にならず疲れにくい音 |
| F4 | 音のシャワー | 顔や体に音が降り注ぐようなスピーカー配置のイメージ |
| F5 | 限定配信 | 一般公開しないクローズドな配信形態（一般の人からは見えない限定的なもの） |
| F6 | 常時再生 | **運転中はずっと流し続ける**のが基本方針（7/31確定）。一定音量。実験知見では**最低10分で自律神経に変化** |

## 5. ハード面の検討事項（提案が求められている論点）

- **再生デバイス**: 外付けスピーカー vs スマホ再生
  - スマホが「一番フレキシブルでどんな状態でも対応できる」として有力視。ただし**未決定**
  - スマホをカップホルダー的なマウントで固定する案あり
- **音源の置き場所**: 端末内蔵か配信か
- **スピーカー設置位置**: 運転の邪魔にならない位置
- **量産時の展開**: 数百台導入のため、トヨタ・いすゞ等に「この位置にスピーカーを付けてほしい」とスジャータ側から要請できる可能性あり

## 6. ロードマップ

| フェーズ | 内容 |
|---|---|
| 導入 | **まず波動研究所のオフィス内で自然音を流すことからスタート**（7/31に圭一郎さんが推奨・8/21訪問時に音源持参の可能性） |
| 短期 | 既存トラック・既存ドライバーで**実証実験**（どんな音・どんな方式が良いかの検証。複数回実施し、やり方を修正しながら進める） |
| 中期 | 夜の睡眠環境（自宅・会社）への音提案／先方社内・工場勤務者への展開／運転前の生活習慣提案（クライアント了承済み） |
| 長期 | トヨタ等の自動車メーカーと連携し、「健康になるトラック」を車両設計段階から標準搭載 |

### 6.1 効果測定の候補（7/31協議済み）

| 方法 | 位置づけ |
|---|---|
| POMS心理テスト（35項目） | **最も簡便**。出発前・運転直後・帰着後の3回で変動を見る |
| 心拍数・血圧 | 測定前に5〜10分の安静が必要（直前の心理要因で乱れるため） |
| 唾液検査（オキシトシン・セロトニン・コルチゾール） | 採取後すぐ冷凍が必要。費用高め |
| 波動測定装置（クライアント保有） | **先方が強く実施したい意向**。他データとの整合性・連動性を確認しながら活用 |

## 7. 制約・前提

- まずはトラック（車内）から着手。工場・睡眠環境は後続
- 操作性最優先: ドライバーに操作の負担をかけない
- 音源選定の責任はジョイファウンデーション側（システム提案とは分離）

## 8. 要確認事項

1. **発案者の氏名**: 創業会長・日比孝吉氏は2017年に逝去。7/31打ち合わせで「現代表も日比氏」と判明したが、フルネームは要確認
2. 研究所の正式名称の最終確認（「めいらく波動医科学研究所」表記で良いか）
3. スマホ再生の場合、ドライバー私物か会社支給か（数百台規模の運用に直結）
4. 実証実験の規模・時期（評価指標の候補は7/31協議済み → §6.1）
5. 予算感・契約形態（システム開発の受託範囲）
