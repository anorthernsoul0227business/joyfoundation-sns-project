# ミニ圭一郎チャットボット（練習用）

サウンドヒーリング協会について、プロジェクト内の資料をもとに答えるチャットボットです。
Python と Claude API で作っています。

> ⚠️ 練習用です。外に公開する前に、必ず圭一郎さんの了承と確認をいただいてください。
> 資料のカードの多くはまだ「draft（未承認）」です。

## ファイル

| ファイル | 役割 |
|---|---|
| `persona.md` | キャラクターの設定と答え方のルール（**いちばんよく直すところ**） |
| `mini_keiichiro.py` | チャットボット本体 |
| `test_questions.md` | 確認用の質問集（22問） |

## チャットボットに渡している資料

`mini_keiichiro.py` の `build_reference()` で、次の資料を自動で読み込みます。

- `CLAUDE.md` の「団体情報」
- `資料まとめ.md`（協会誌のまとめ）
- `knowledge/voice/` 圭一郎さんの言葉（`usable: 可` のものだけ）
- `knowledge/evidence/` 研究データ（`disputed` の EV-0002 は外す）
- `knowledge/testimonial/` 体験談（`usable: 可` のものだけ）
- `knowledge/glossary.md` 用語の説明
- `knowledge/editorial/` 表現のルール

全部で約13万文字です。これくらいならAIが一度に読めるので、資料を丸ごと渡しています。

## 動かし方

### 1. 準備（最初の1回だけ）

```bash
pip install anthropic python-dotenv
```

APIキーを https://platform.claude.com で作り、プロジェクト直下の `.env` に書きます（`.env` は git に上がらない設定になっています）。

```
ANTHROPIC_API_KEY=sk-ant-...
```

### 2. 資料が読めているか確認（API は呼ばない・無料）

```bash
python chatbot/mini_keiichiro.py --dry-run
```

### 3. 会話する

```bash
python chatbot/mini_keiichiro.py
```

答えのあとに、使ったトークン数が表示されます。

## 料金の目安

毎回、約13万文字の資料を一緒に送っています。ただし「キャッシュ」を使っているので、最初の1回より2回目以降のほうがずっと安くなります。

- 最初の質問：資料を読み込むので、100円前後
- 1時間以内の次の質問：資料はキャッシュから読むので、数円程度

表示の「キャッシュ読込」が0のままなら、キャッシュが効いていません。

## 練習の進め方

1. `test_questions.md` の質問を順に聞いて、結果欄に ○△× をつける
2. × が出たら、`persona.md` のルールを直す（足す・言い方を変える）
3. もう一度同じ質問をして、直ったか確かめる。ほかの質問が悪くなっていないかも確認する

### 試してみると面白い変更

- `mini_keiichiro.py` の `effort` を `"low"` → `"medium"` にすると、答えがどう変わるか
- `persona.md` の「話し方」を変えて、キャラクターの印象がどう変わるか
- 資料から `資料まとめ.md` を外すと、どの質問に答えられなくなるか

## 次の段階（C）

- 資料が増えて一度に渡せなくなったら → 関係する部分だけを探して渡す（RAG）
- 画面をつける → ブラウザで話せるWebページ、または公式LINEにつなぐ
